STEP 01 · MENTAL MODEL

一分鐘白話比喻：把現代 AI 系統想成一間「米其林智慧廚房」

在看技術架構前，先用最直覺的餐廳廚房比喻，秒懂這 5 個最常聽到的名詞分別扮演什麼角色：

🧠 核心推理

LLM (大語言模型)

👉 比喻：智商極高但關在房間裡的大腦

很會推理、寫作與進行內部思考 (Thinking)，但本身沒有手腳，無法自己讀你的電腦檔案，也不知道資料庫現在有什麼。

💭 思考過程計入 Output Tokens
🤖 自主執行迴圈

Agent (AI 代理)

👉 比喻：擁有手腳與規劃能力的總主廚

把 LLM 包在「感知 → 思考 → 行動 → 觀察」迴圈裡。遇到問題會自己決定先查檔案、跑測試、看到報錯再自己修好！

🔄 每走一步迴圈，歷史 Context 重送一次
📚 按需載入秘笈

Skills (技能包 / SKILL.md)

👉 比喻：書架上的專業食譜與專用模具

平時主廚腦中只記著「書名目錄」（極省空間）；當客人點了「舒芙蕾」時，才去書架翻開那本食譜 (`SKILL.md`) 與附帶腳本照著做！

✨ 平時僅 ~35 tokens，用到才載入全文
🔌 萬用外接標準

MCP (模型上下文協定)

👉 比喻：廚房牆上的 USB-C 萬用插座

統一的連接標準！插上 GitHub MCP 就能發 PR，插上 Postgres MCP 就能查資料庫，不用為每台烤箱重拉電線。

⚠️ 掛載越多工具，常駐 Schema 越耗 Token
🕵️ 獨立分身小隊

Subagents (子代理)

👉 比喻：派去市場採買調查的二廚分身

去另一個房間翻閱 50 份食材報告（消耗大量 Token），但最後只拿一張「300 字結論便利貼」回報給總主廚，完全不弄亂主廚房！

🛡️ 獨立 Context Window，主對話超乾淨
